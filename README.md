## Enunciado: Integração de Sensor de Presença (PIR) e LED

Projeto focado na integração de sensores e atuadores para automação de tarefas em sistemas de IoT. O circuito utiliza um sensor de presença infravermelho (PIR) para identificar eventos de movimento e acionar automaticamente um LED como resposta visual.

- **Detecção:** O sensor PIR monitora o ambiente e envia um sinal digital ao Arduino quando detecta movimento
- **Acionamento:** O Arduino processa a entrada do sensor e liga o LED correspondente
- **Automação:** O LED permanece aceso enquanto houver presença detectada e apaga quando o movimento cessa
